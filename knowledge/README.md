# knowledge/

这个目录默认是空的。

仓库不附带任何第三方版权语料（角色设定、同人对话、梗图、新闻正文、赛事文章等）。请只放入你有权使用的 JSON / Markdown 资料，例如：

- 自己写的群规、术语表、FAQ；
- 有明确授权的资料；
- 公开数据的事实字段（赛程、比分、版本号等）。

启动时 `knowledge.update_on_start` 会自动抓取公开的 LOL 赛程、体育数据、新闻 RSS 和 B 站热榜到对应子目录；这些脚本的代码在 `tools/` 中，抓取结果由你自行确认使用范围。

RAG 使用方式见根目录 README 的“RAG 与搜索”一节。
